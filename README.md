## 設計概念

整體走「**新世代宣言 ✕ 前瞻數位感**」的編輯風格——這是四位候選人中**最大膽、最年輕**的設計。

### 為什麼是這個風格？

- 候選人 **30 歲**，是四位民眾黨員林市代表 + 彰化市代表參選人中最年輕的
- 口號「**換少年來拚**」直接擁抱青年世代換血訴求
- 政見明確點名「不只清水溝、修路燈的高級里長」——是**世代差異最鮮明**的候選人
- 因此整套視覺刻意走出舒適圈，採用螢光綠 × 深墨綠的高對比配色

### 配色策略

- **主色：深墨綠（#0d1f1a）** ── 沉穩、地球感、永續政治
- **強調色：螢光萊姆綠（#c8f04c）** ── 新世代、未來感、能量
- **底色：奶油白（#fafaf5）** ── 留白、清爽、編輯感

### 字體策略

- **中文標題**：Noto Serif TC 900（莊重、有氣勢）
- **西文展示字**：Space Grotesk 700（當代設計感、新創公司風）
- **西文標籤字**：JetBrains Mono（程式碼字體、傳達理性與技術感）
- **中文內文**：Noto Sans TC（清楚易讀）

### 獨家設計亮點

1. **「換少年宣言」獨立區塊（#manifesto）** ── 開場第一個區塊就是大字宣言，三行文字「不只清水溝、不只修路燈、換個方法做事」用 strikethrough 劃掉舊做法。這是其他三位完全沒有的劍走偏鋒設計。
2. **口號「東區/少年」黃綠塊處理** ── 把口號中的關鍵字用螢光綠色塊框起來、微微傾斜，一眼就能記住。
3. **巨大背景數字 04** ── Hero 與 CTA 都有超大號數字當水印，加深號次記憶。
4. **網格背景** ── Hero 的螢光綠網格背景帶出「都市規劃藍圖」的暗示，呼應「打造宜居東區」的核心政見。
5. **完整的選舉資訊欄 + 線上陳情表單 + 法律合規聲明** ── 沿用張嘉龍站的最佳實踐。

## 修改指南

### 替換圖片
把新圖放進 `images/` 資料夾，**檔名保持一致**即可。

### 主色調修改
HTML 開頭的 `:root` 變數定義：

```css
:root{
  --bg:#0d1f1a;          /* 深墨綠主底色 */
  --bg-deep:#08140f;     /* 深底色加深版 */
  --lime:#c8f04c;        /* 螢光萊姆綠（核心強調色）*/
  --lime-bright:#d6ff5c; /* 螢光綠亮版 */
  --paper:#fafaf5;       /* 奶油白底色 */
}
```
